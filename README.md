# BAR REALTA（レアルタ）公式Webサイト

吉祥寺北町の BAR REALTA を紹介する、HTML・CSS・JavaScript の静的サイトです。黒と落ち着いたゴールドを基調に、PC・スマートフォンの両方に対応しています。ビルドや外部ライブラリ、API キーは不要です。

## ファイル構成

- `index.html`：全7セクション、店舗情報、SEOメタデータ、BarOrPub構造化データ
- `assets/style.css`：レスポンシブデザイン、装飾、アクセシビリティ対応
- `assets/main.js`：スマートフォンのナビゲーション開閉
- `assets/favicon.svg`：サイトアイコン
- `assets/images/`：提供された実店舗写真4枚（店内全景・カウンター・酒棚・外観）

## ローカルで確認

リポジトリのルートで実行してください。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8000` を開きます。停止するには Ctrl+C を押してください。依存パッケージのインストールは不要です。

## 公開

GitHub の main ブランチへの保存と、Webサイトの公開は別の操作です。GitHub Pages を利用する場合は、リポジトリの Settings → Pages で「Deploy from a branch」、`main`、`/ (root)` を選択します。ほかの静的ホスティングでも、これらのファイルをそのまま配信できます。

公開URLが決まったら、`index.html` に実際のURLを使った canonical、`og:url`、構造化データの `url` を追加してください。必要に応じてサイトマップを作成し、Google Search Console に登録します。基本SEOは設定済みですが、検索順位やインデックス登録を保証するものではありません。

## 動作確認のポイント

PCとスマートフォンで横スクロールが発生しないこと、各セクションへの移動、モバイルメニューの開閉・Escapeキーでの閉じ方、電話・マップのリンクを確認してください。JavaScriptを無効にしてもナビゲーションと主要コンテンツを利用できます。キーボード操作用のフォーカス表示、本文へのスキップリンク、動きを減らす設定にも対応しています。

## 実店舗写真

写真は `assets/images/` に元のJPEGのまま保存しています。店内全景を大きく、カウンターと酒棚を本文と組み合わせて配置し、外観は入口・看板が確認できるよう全体を表示しています。各写真に代替テキスト、寸法、遅延読み込みを設定しています。スマートフォンでは縦方向のレイアウトに切り替わります。

写真を差し替える際は、ファイル名・画像寸法・alt・キャプションを確認してください。写真内の価格やメニューだけを根拠に掲載情報を変更せず、店舗に現在の提供内容を確認してください。
