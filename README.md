# BAR REALTA（レアルタ）公式Webサイト

吉祥寺北町の BAR REALTA を紹介する、HTML・CSS・JavaScript の静的サイトです。黒と落ち着いたゴールドを基調に、PC・スマートフォンの両方に対応しています。ビルドや外部ライブラリ、API キーは不要です。

## ファイル構成

- `index.html`：HOME（メインビジュアル）
- `about.html`：ABOUT（レアルタについて）
- `drink.html`：DRINK（ドリンク・サービス）
- `darts.html`：DARTS（ダーツ）
- `shisha.html`：SHISHA（シーシャ）
- `sunday-bar-owner.html`：SUNDAY BAR OWNER（日曜オーナー募集）
- `information.html`：INFORMATION（店舗情報・アクセス）
- `contact.html`：CONTACT（電話でのお問い合わせ）
- 各ページは共通ヘッダー・フッター、ページ別SEOメタデータ、既存のGA4タグとBarOrPub構造化データを使用します。
- `assets/pages.css`：共通ナビゲーションと専用ページのレイアウト。ダーツ・シーシャの写真は既存の合成画像をCSSで表示範囲を分けて使用し、元ファイルは変更しません。
- `assets/style.css`：レスポンシブデザイン、装飾、アクセシビリティ対応
- `assets/main.js`：スマートフォンのナビゲーション開閉
- `assets/favicon.svg`：サイトアイコン
- `assets/images/`：提供された実店舗写真4枚（店内全景・カウンター・酒棚・外観）

## ローカルで確認

リポジトリのルートで実行してください。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8000` を開きます。各HTMLを直接開いて確認でき、内部リンクと素材パスはGitHub Pagesのサブディレクトリにも対応する相対パスです。停止するには Ctrl+C を押してください。依存パッケージのインストールは不要です。

## 公開

GitHub の main ブランチへの保存と、Webサイトの公開は別の操作です。GitHub Pages を利用する場合は、リポジトリの Settings → Pages で「Deploy from a branch」、`main`、`/ (root)` を選択します。ほかの静的ホスティングでも、これらのファイルをそのまま配信できます。

公開URLが決まったら、`index.html` に実際のURLを使った canonical、`og:url`、構造化データの `url` を追加してください。必要に応じてサイトマップを作成し、Google Search Console に登録します。基本SEOは設定済みですが、検索順位やインデックス登録を保証するものではありません。

## 動作確認のポイント

PCとスマートフォンで横スクロールが発生しないこと、各セクションへの移動、モバイルメニューの開閉・Escapeキーでの閉じ方、電話・マップのリンクを確認してください。JavaScriptを無効にしてもナビゲーションと主要コンテンツを利用できます。キーボード操作用のフォーカス表示、本文へのスキップリンク、動きを減らす設定にも対応しています。

## 実店舗写真

写真は `assets/images/` に元のJPEGのまま保存しています。店内全景をトップの背景として使用し、カウンターと酒棚を本文と組み合わせて配置し、外観は入口・看板が確認できるよう全体を表示しています。各写真に代替テキストと寸法を設定しています。トップ写真を優先読み込みし、その他は遅延読み込みしています。トップ写真は縦横比を保ったまま画面幅に合わせてトリミングされます。スマートフォンでは縦方向のレイアウトに切り替わります。

写真を差し替える際は、ファイル名・画像寸法・alt・キャプションを確認してください。写真内の価格やメニューだけを根拠に掲載情報を変更せず、店舗に現在の提供内容を確認してください。

## フォント

英字は Cormorant Garamond、日本語は Noto Serif JP を使用しています。本文は Regular、大きな日本語コピーは Light、英字ラベルは Medium を基本としています。可読性を保つため、細身の英字ラベルと本文の文字サイズも調整しています。フォントは Fontsource 5.3.0 のパッケージから取得した WOFF2 を `assets/fonts/` に保存し、`assets/fonts.css` から読み込みます。外部フォントサービスへの接続は不要です。SIL Open Font License のライセンス文書も同フォルダに同梱しています。
